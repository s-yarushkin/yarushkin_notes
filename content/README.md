# Внутренний порядок — контент-архив

Этот каталог хранит тексты Telegram-канала «Внутренний порядок | Сергей Ярушкин», чтобы опубликованные посты и рабочие черновики не терялись между чатами.

## Структура

- `published/` — архив уже опубликованных постов по месяцам.
- `drafts/backlog.md` — отложенные и будущие темы/черновики.

Архив опубликованных постов собран из Telegram-экспорта, актуального по 28 августа 2026 года.

Правило: опубликованный текст сохраняем как историческую версию и не переписываем задним числом. Новые версии, продолжения и переосмысления идут отдельными черновиками/постами.
